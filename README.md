# RO 純單機 H5 放置 RPG

目前公開版本：**MVP 3.2**（延續 MVP 3.1 存檔安全；新增已核對 ACT／SPR 來源的波利與狼進場移動動畫。）

這個倉庫是遊戲本體。技術採純 HTML、CSS、JavaScript，無建置工具、無後端帳號服務。

## MVP 0.4 可玩的內容

- 首次按下按鈕才準備第一張地圖的必要素材，驗證檔案大小與 Git blob SHA-1；每項素材最多 3 次自動嘗試，已驗證的素材會保留，失敗狀態可手動重試；後續地圖素材首次進入時才下載。
- 素材存入瀏覽器 IndexedDB；遊戲外殼由 Service Worker 快取。
- 三個角色槽、初心者創角、名稱驗證、更名與安全刪除。
- 共用 Zeny 與帳號倉庫；角色進度分槽保存。
- 新手營地、六張練功地圖（新手訓練場、普隆德拉原野兩張、培恩森林、摩洛克沙漠、迷藏森林地洞）、共 16 種怪物遭遇與 1×／2×／3×速度。MVP 1.7 起地圖卡片會列出各怪物依本遊戲權重換算的預估遇敵率；MVP 1.8 再於怪物圖鑑逐張列出該怪物在各地圖的預估機率及目前等級是否可進入。所有機率都明確標註為原型設定，不代表官方刷新機率。MVP 1.9 起圖鑑只顯示通過完整性驗證、已在本機載入的怪物縮圖，旁邊顯示 Mob ID；缺圖時顯示未載入提示，不會誤用波利或其他怪物圖片。MVP 2.0 在開啟圖鑑時只讀取本機 IndexedDB 既有縮圖、重新驗證大小與 SHA-1 後恢復顯示；不觸發額外網路下載。
- 暫停、手動儲存、最多 24 小時離線結算與收益摘要。
- 在角色選擇畫面可將全部 3 個角色槽、共用 Zeny、倉庫、裝備與卡片匯出成 `.rosave`；也可匯入 `.rosave`／相容的舊版 JSON。匯入先完整檢查格式與欄位，較新版本的存檔會拒絕匯入；覆蓋本機存檔前必須完成兩階段確認，最後寫入後會回讀驗證。
- MVP 3.1 起每次帳號存檔會先保存一份上一個已驗證的主存檔字串（同一瀏覽器的 `ro-h5-account-backup-v1`），再重新比對主存檔後提交新內容。若儲存空間不足以建立備份，或現有主存檔未通過完整性檢查，主存檔不會被改寫；遇到主存檔損壞時，可從安全停止畫面或角色選擇頁手動還原上一份備份。備份可能落後目前遊戲幾秒，復原前會要求確認。
- 依使用者要求，已取消帳號分頁鎖、接管流程與唯讀阻擋畫面。MVP 3.1 會以儲存事件與寫入前比對偵測大多數跨分頁更新；偵測到衝突後只暫停該分頁寫入、保留其記憶體進度，提供 `.rosave` 恢復備份與載入最新存檔，不會跳到阻擋遊戲的鎖定畫面。多分頁同時操作仍存在極短的競爭窗口，建議同一時間只在一個分頁進行修改。
- 升級獲得能力點，能逐點分配 STR／AGI／VIT／INT／DEX／LUK；加點會影響原型戰鬥數值。
- 初心者達到原型 Job Lv. 10 門檻後，可選擇劍士／魔法師／弓箭手／服事／商人／盜賊；職業各有原型被動，轉職不會清除 Base 等級或共用資產。
- 依職業與性別按需載入 14 組角色動畫、共 120 張畫格；每張均檢查檔案大小及 Git blob SHA-1，逐格循環播放。下載失敗時仍保留內建 SVG 備援。
- 暴擊時播放 15 張 RO 特效逐格動畫；素材只在第一次觸發時下載，逐張驗證後快取。
- 戰鬥音效可切換開／關；普通命中、暴擊、升級及狂擊、火箭術、靈魂打擊、二連矢、治癒術、金錢攻擊、施毒有對應音效，首次觸發才按需下載並驗證大小與 Git blob SHA-1。
- 新增初心者與六種一轉職業的原型技能樹；Job 等級提升會獲得技能點，可學習被動加成與自動戰鬥技能，SP／Zeny 消耗、冷卻與效果都在核心戰鬥中處理。
- 主動技能有斬擊、魔法、箭矢、重擊、治癒與毒屬性的戰鬥視覺效果；受擊怪物會依技能類型播放不同衝擊動畫。
- 怪物命中／擊倒保留既有視覺特效；波利 Mob 1002 使用 action 0 待機（4 格，每格 160ms）、action 16 攻擊（28 格，每格 40ms）及 action 24 受擊（5 格，每格 160ms）；瘋兔 Mob 1063 使用 action 2 待機（12 格，每格 80ms）及 action 18 攻擊（19 格，每格 40ms）；狼 Mob 1013 使用 action 0 待機（15 格，每格 120ms）及 action 16 攻擊（7 格，每格 120ms）。受擊動作僅在非致死命中時播放；所有動作均採配對 ACT／SPR，核對畫格引用與時間後逐格接入。MVP 3.2 新增波利 Mob 1002 移動 action 8（10 格，每格 40ms）與狼 Mob 1013 移動 action 8（8 格，每格 80ms）；擊倒後會以非必要、按需載入的對應物種動畫短暫呈現新怪物進場，播放完回到原有待機圖。素材失敗不會阻擋戰鬥或收益。綠色植物 Mob 1080 維持 12 格待機（每格 160ms）與被動不反擊。除已核對的動作外，不把未確認的 ACT action 冒稱攻擊／受擊／死亡動畫；所有戰鬥平衡值仍是遊戲原型設定，不代表台灣官方現行數值。
- 可重現的怪物動畫產製流程：固定版 ACT／SPR 樣本存於 `tools/samples/`；`node tools/render_monster_act_spr.js --write` 可重產十一個 SVG（含波利受擊動畫、瘋兔／狼攻擊動畫、綠色植物待機動畫及同物種靜態備援），`npm test` 會以 `--check` 比對位元完全一致的正式輸出。這是開發工具，不影響遊戲 runtime，也不需玩家安裝額外套件。
- 新增怪物圖鑑：各角色分別記錄擊倒數，擊倒後解鎖該怪物的 HP、出沒地圖及目前原型資料列出的掉落品；尚未遭遇的怪物顯示為未知。MVP 1.6 加入已發現怪物名稱搜尋、遭遇狀態篩選與擊倒數排行，且搜尋不會揭露尚未遭遇怪物的名稱。既有角色會安全補上新欄位，既有進度不重設。
- 新增裝備／卡片系統：四個裝備欄位、共用裝備背包、裝備替換／卸下、單槽卡片鑲嵌及裝備屬性戰鬥加成。波利、綠棉蟲、瘋兔與盜蟲有機會掉落原型裝備或卡片；離線收益摘要也會列出獲得的裝備。
- MVP 1.3 將裝備擴充至 14 件、卡片擴充至 6 張，新增短劍、長劍、弓、不同護甲／鞋子／飾品與新卡片，並把掉落加入蛹、狼、孢子、柳精、半獸人、大嘴鳥、禿鷹等對應怪物。
- 裝備的閃避加成與 Zeny 獲得加成已接入實際戰鬥結算，不只顯示在裝備資料中；各裝備仍依 Base 等級與職業條件限制裝備。
- MVP 1.5 核對怪物實際 Mob ID 與圖片來源，修正既有錯配並加入映射／檔案大小／Git blob SHA-1 回歸測試。MVP 1.9 對全部 15 種怪物加入來源 ID 與專屬素材對照檢查；MVP 2.0 讓圖鑑只從本機 IndexedDB 還原已驗證縮圖，不重新下載、不套用其他怪物圖片。MVP 2.1 將 Divine Pride 的盜蟲 Mob 1051 PNG 固定為 1,783 bytes 與 Git blob SHA-1，加入本機素材清單；圖片缺失時保留明確的向量備援，不會改用殭屍圖。這張 PNG 是靜態縮圖，並不代表盜蟲的正式逐格動畫已接入。MVP 2.2 再修正戰鬥畫面 fallback：其他怪物圖像缺失或未驗證時顯示「圖像未載入」佔位，不會靜默用波利圖片代替。MVP 2.3 以配對 ACT／SPR 解析瘋兔 Mob 1063 與狼 Mob 1013 的待機畫格，採非阻塞延遲載入並在執行前驗證大小與 Git blob SHA-1。
- MVP 1.4 新增 3 種材料合成配方：胡蘿蔔補給、果凍治療藥與蜂蜜藥水。製作會扣除共用倉庫材料，成品可在倉庫手動使用並恢復 HP；滿 HP 時不會浪費道具，離線戰鬥不會自動消耗。
- 新增裝備安全精煉：四個欄位已裝備的物品可消耗共用 Zeny 精煉至 +5；武器增加攻擊、鎧甲／鞋子增加防禦、飾品增加爆擊率。此原型保證成功、不會破壞裝備或卡片，+0 的既有裝備會安全補欄位。
- 新增卡片取出與移轉：可從已穿戴或共用背包的裝備取出卡片，卡片回到共用倉庫、裝備本身與精煉等級保留；取出後卡片的戰鬥加成立即移除。
- 新增裝備出售：背包裡沒有已鑲嵌卡片的裝備可出售換取共用 Zeny。出售按確認後完成，精煉花費不退還；仍穿戴中的裝備不能出售。
- 地圖背景音樂使用獨立開關，進入地圖後只載入目前曲目；已驗證曲目會留存在瀏覽器快取。

## 執行與測試

需要 Node.js 執行單元測試。瀏覽器遊玩請使用 HTTPS 或 localhost（雜湊驗證與 Service Worker 需要安全環境）。

- 安裝不需要依賴套件。
- 執行測試：**npm test**
- 本機啟動：**npm run serve**
- 開啟網址：http://localhost:8000/

不建議直接以 file:// 雙擊開啟，因為瀏覽器通常會限制安全雜湊驗證、IndexedDB 及 Service Worker。

## 自動版本更新

遊戲每次開啟都會檢查 Service Worker 更新；HTML、CSS、JavaScript 採網路優先並重新驗證，離線時才回退到本機快取。偵測到新版後，已開啟的遊戲分頁會自動重新載入，不需要使用者按 `Ctrl+F5`。角色進度仍保存在瀏覽器本機存檔中。
