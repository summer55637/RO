# 迷你 RO：米德加爾特小冒險

一款免費、純前端、可離線的 RO 風格單機小 RPG。目標不是複製正服所有細節，而是保留最有趣的核心：**打怪、升級、配點、學技能、換職業、撿裝備**。打開網站就能玩，不需要帳號、下載或後端伺服器。

- 遊戲網址：<https://summer55637.github.io/RO/>

## 30 秒上手

1. **看畫面上的新手提示，點波利**：角色會自動追過去攻擊；第一隻怪物倒下和升級時，畫面會告訴你下一步。
2. **升級變強**：第一級只需 25 EXP，之後每級多 10 EXP；每次 Base 升級得到 3 點能力值與 1 點技能點。
3. **配點學技能**：每次提升能力值固定花 1 點；技能卡會標示攻擊、魔法、範圍、治療、輔助或被動。未學會時點一下學習，學會後卡片會顯示「點擊施放」。
4. **喝紅水**：HP 不夠時點「使用紅色藥水」。
5. **直接轉職**：在「角色」選單選擇目標職業，按「直接轉職」。不跑任務、不收費；一轉需要 Base Lv. 5，二轉需要 Base Lv. 20 並先完成對應一轉。
6. **免費重置**：能力值和技能都可以隨時免費初始化，再重新分配。

畫面會依 Base 等級推薦練等地圖與怪物，可以直接按「前往推薦地圖」或「追蹤推薦怪物」。怪物圖鑑也會標示新手、初階、中階、進階、高難度或 Boss 挑戰，並提供建議等級。點擊地面可以移動；地圖選單先列出「新手推薦」，城鎮和較難的地下城分開分類。畫面只保留 HP、SP、EXP、藥水和技能等主要資訊；攻擊速度、暴擊等次要數字不再佔據主畫面。裝備、背包與存檔放在次要選單，不影響新手直接開始打怪。

## 迷你版規則

- 能力值只有 STR、AGI、VIT、INT、DEX、LUK 六種；加點每次固定 1 點。
- Base 等級是主要轉職條件；簡化版不使用 Job Lv. 作為二轉門檻。
- 職業只顯示符合目前階段的選項，並直接標示簡短定位，例如近戰耐打、遠距魔法、治療支援，讓玩家不必背職業表。
- 進階系統（例如寵物、任務、精煉、卡片與放置／離線狩獵）不放在主要玩法中。
- 技能最多保留少量核心選項；卡片直接標示技能用途、學習狀態與使用提示。主狀態顯示職業定位，不用 Job EXP 混淆新手。
- 練等推薦覆蓋 Base Lv. 1–99，每個等級區間都指定實際存在的地圖與怪物；升級時會自動更新推薦。
- 戰鬥採固定普通攻擊傷害，不會隨機打空；怪物 HP／攻擊／防禦降低，EXP 提高，Boss 仍比較強。
- 紅色藥水恢復 45 HP；每級需求 EXP 從 25 開始，每級固定增加 10。
- 戰鬥數值、技能效果、EXP 與掉落是為了容易上手而調整的**迷你版遊戲化設定**，不宣稱與台灣 RO PC 正服公式或資料完整相同。

## 存檔與開發

- 進度存在瀏覽器 LocalStorage，可匯出／匯入 JSON 存檔。
- GitHub Pages 網址：<https://summer55637.github.io/RO/>
- 本機檢查：`node scripts/smoke-test.js` 與 `node scripts/official-content-audit.js`。
- `data/official-content-registry.json` 保留官方來源研究紀錄，只用於追蹤證據與資料缺口，不再用「尚未完成官方逐筆核實」阻止迷你版遊戲發布。

## 素材與範圍

本專案不是官方客戶端，也不連接官方伺服器；沒有官方美術授權素材時會使用原創 Canvas 繪圖。遊戲目前是單機版本，不提供多人連線、共用經濟、公會、交易或攻城戰。
