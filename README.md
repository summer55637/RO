# RO 純單機 H5 放置 RPG

這個倉庫是遊戲本體。技術採純 HTML、CSS、JavaScript，無建置工具、無後端帳號服務。

## MVP 0.1 可玩的內容

- 首次按下按鈕才準備第一張地圖的必要素材，驗證檔案大小與 Git blob SHA-1；每項素材最多 3 次自動嘗試，已驗證的素材會保留，失敗狀態可手動重試；後續地圖素材首次進入時才下載。
- 素材存入瀏覽器 IndexedDB；遊戲外殼由 Service Worker 快取。
- 三個角色槽、初心者創角、名稱驗證、更名與安全刪除。
- 共用 Zeny 與帳號倉庫；角色進度分槽保存。
- 新手營地、兩張初期地圖、波利／瘋兔／綠棉蟲／蛹／盜蟲遭遇，與 1×／2×／3×速度。
- 暫停、手動儲存、最多 24 小時離線結算與收益摘要。
- 帳號操作鎖與分頁接管；舊分頁失去權限後停止戰鬥及寫入。

## 執行與測試

需要 Node.js 執行單元測試。瀏覽器遊玩請使用 HTTPS 或 localhost（雜湊驗證與 Service Worker 需要安全環境）。

- 安裝不需要依賴套件。
- 執行測試：**npm test**
- 本機啟動：**npm run serve**
- 開啟網址：http://localhost:8000/

不建議直接以 file:// 雙擊開啟，因為瀏覽器通常會限制安全雜湊驗證、IndexedDB 及 Service Worker。
