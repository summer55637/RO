## MVP 1.0 存檔相容性

- 舊帳號若缺少 `equipmentInventory`，讀取時補成空陣列。
- 舊角色若缺少 `equipment`，第一次需要裝備資料時才補上四個空欄位。
- 每件裝備以獨立 instance 儲存；裝備與附帶卡片會在卸下或刪除角色時一併保留，裝備回到帳號共用背包。
- 不變更存檔版本或 `ro-h5-account-v1` key，不重設角色、技能、能力點、Zeny、共用倉庫、圖鑑或既有獎勵。
